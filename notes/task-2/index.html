怎么理解"跑通"？

code/D1/d1_1 ~ d1_6 是课程给出的六个递进式示例脚本，不是要你从零写代码，而是：

  1. 读懂每个脚本在演示什么（从一次调用 → 多轮 → 流式 → 绑工具 → 接真向量库 → Agent 循环）
  2. 亲手跑一遍，看真实输出（python code/D1/d1_1_base.py 依次到 d1_6_agent.py）
  3. 改一改（可选）比如换个模型名、改问题，观察输出变化

课程设计的意图是让你通过"运行"来建立直觉——同一件事（问 seekdb 怎么检索），在六个脚本里的实现方式逐级变复杂，能力也逐级变强。
