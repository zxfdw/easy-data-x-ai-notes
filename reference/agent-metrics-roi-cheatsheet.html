Agent 度量与 ROI

一页纸：四层指标口径、ROI 三情景怎么读、以及把证据做成可复现的四件套。

离线评测四层指标

层指标实测值（30 例）
数据层知识覆盖率 / 检索命中率 / 检索故障率82.76% / 95.83% / 3.33%
模型层回答准确率 / 幻觉率96.67% / 3.33%
业务层任务成功率 / 转人工率 / 行为一致率73.33% / 23.33% / 100.00%
运行层工具成功率 / 平均延迟 / 平均 Token80.00% / 108.67ms / 23.53

看点：检索命中率 95.83%，任务成功率只有 73.33%。差的 20 多个点出在转人工、缺知识、工具失败等具体环节——分层看，才定位得到该改哪里。

ROI 三情景怎么读

情景净收益ROI回收期盈亏平衡
conservative-3,644 元-24.46%107.89 月115 单/月
base+9,200 元67.65%3.64 月52 单/月
optimistic+25,784 元188.92%1.61 月37 单/月
  1. 先看保守情景亏不亏。 亏钱是实话——业务量不够、转人工率高时，Agent 就是划不来的。
  2. 再看盈亏平衡任务量。 它比 ROI 更直接地回答"要做到多大规模才值得上"，是可以对齐目标的门槛。
  3. ROI 是结果，门槛是决策依据。 汇报时两个都要，别只报漂亮的那个。
