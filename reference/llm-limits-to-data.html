速查表 · 可打印（对应 F1 / F2）

症状 → 数据缺口

AI 不好用时，先别换模型。查这张表找缺哪种数据。

先问一句

大模型只有训练数据，没有你的数据。
所以"AI 不好用"的第一反应不该是换更强的模型，而是问：它缺的是哪种数据？

症状对照表

你看到的症状缺的数据该补什么
答得流畅，但细节是错的可验证的事实数据可检索的知识库（RAG）
说"我不知道"，或给的是旧信息实时数据接入会持续更新的数据源
答案正确，但跟我没关系用户 / 业务数据记忆系统（Memory）

四个热词的数据本质

能力数据本质效果取决于
RAG知识数据的检索知识库数据质量 + 检索策略
MCP数据接入的标准化数据接口的标准化程度
Skill经验数据的结构化技能的结构化程度 + 可检索性
Memory数据的积累与召回记忆数据的提炼质量 + 召回策略

两句话

AI 的能力上限 = 数据质量 × 模型能力
换模型是乘法的一项，补数据是另一项；当数据为 0，模型再强也是 0。
模型决定能"想多好"，数据决定能"做多好"
遇到新概念先问：它在数据层面解决什么问题？答案通常就清楚了。

Agent 的运行形态（F2）

传统对话：用户输入 → 模型生成 → 返回结果        （单次）

Agent：  推理 → 行动 → 观察 → 继续推理 …        （循环）

四个组件：LLM（大脑）/ Planning（规划）/ Memory（记忆）/ Tool Use（工具）
