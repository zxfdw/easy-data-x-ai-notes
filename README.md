# Easy Data × AI 学习打卡笔记

> 🔖 张博 ｜ 🗓️ 2026-09-14 ~ 10-11（29 天）｜ 🖥️ [网页版](https://zxfdw.github.io/easy-data-x-ai-notes/)

**课程简介：** 围绕 **Agent、RAG、Memory、Skill 与 MCP**，理解数据如何影响 AI 应用的效果、边界与工程实现。双轨结构——**道篇**（场景判断/问题归因/系统设计）+ **术篇**（可运行代码）+ **产业应用篇**（真实 AI Native 数据产品）。
